# enuvia together

Der gebaute Stand der App, damit sie unter einer Adresse erreichbar ist.
Hier liegt ausschließlich das Ergebnis — kein Quellcode, keine Spezifikation.

Die App läuft ohne Server: alles, was jemand einträgt, bleibt im Browser
seines Geräts. Es gibt keine Anmeldung und keine Übertragung.

Erzeugt mit `npm run deploy:pages`. Von Hand geändert wird hier nichts —
jeder Lauf ersetzt den Inhalt vollständig.
